### What I Do

* **Vibe Coding &amp; Rapid Prototyping:** Transforming product concepts into production-grade systems with extreme velocity using AI-native workflows, prompt engineering, agentic loops (Claude Code, Cursor), and continuous automated iteration.
* **Full-Stack Web Architecture:** Designing modern, responsive interfaces and robust serverless or containerized backend applications with Next.js, React, TypeScript, Node.js, and Tailwind CSS.
* **Local LLM &amp; AI Engineering:** Deploying, fine-tuning, and running local model inference using Ollama, llama.cpp, and LM Studio alongside agentic frameworks like OpenClaw and Hermes.
* **AI &amp; Workflow Automation:** Building autonomous pipelines, function-calling workflows, and webhook integrations with n8n, LangChain, and Model Context Protocol (MCP).
* **Linux Systems &amp; Networking:** Managing Debian and Ubuntu VPS environments, shell automation, Nginx reverse proxies, Docker sandboxes, SSH, and Cloudflare network security.
* **Data &amp; State Persistence:** Architecting relational databases, row-level security policies, and high-speed in-memory caches using PostgreSQL, Supabase, Firebase, and Redis.
